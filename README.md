# THE MACHINE Mobile v0.2

Mobiltilpasset, lokal læringssimulator. Ingen ekstern KI-modell eller API-nøkler.

## Publisering
Koble GitHub-repositoriet til Cloudflare Pages. Framework preset: None; build command: blank; output directory: / (root).

## Bruk
Åpne Pages-adressen i Safari, test «Analyser og lær», og velg Del → Legg til på Hjem-skjerm.

## Begrensninger
Ikke AGI. Strategilæring gjelder kun valg mellom tre algoritmer for delmengdesummer. Hukommelse lagres i nettleseren.
